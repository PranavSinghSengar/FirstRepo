
# Smart Calculator 🧮

A feature-rich, menu-driven calculator developed using C++.

## About the Project

Smart Calculator is my first C++ project.
It performs mathematical operations through
an interactive console-based menu.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power Calculation
- Square Root
- Calculation History
- Clear History
- Input Validation
- Division by Zero Protection

## Technologies Used

- C++
- C++ Standard Library
- STL Vector
- Functions
- Loops
- Conditional Statements
- Switch Statements

## Requirements

- C++17 compatible compiler
- GCC / G++

## How to Run

Compile the program:

    g++ -std=c++17 main.cpp -o calculator

Run on Linux / WSL:

    ./calculator

Run on Windows:

    calculator.exe
