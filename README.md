
# Smart Calculator - C++

A menu-driven calculator built using C++.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Square Root
- Calculation History
- Clear History
- Input Validation
- Division by Zero Protection

## Requirements

- C++ Compiler (G++)
- C++17 or later
- VS Code (optional)

## How to Run

Compile:

    g++ main.cpp -o calculator

Run:

    ./calculator

## Technologies Used

- C++
- STL
- Functions
- Vectors
- Loops
- Switch Statements
- Conditional Statements
